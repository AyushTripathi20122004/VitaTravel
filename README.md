# VitaTravel 🌍

A modern travel website clone built with **React.js**, **Tailwind CSS**, **GSAP**, and **Lenis**.

🔗 **Live Website:** https://ayushtripathi20122004.github.io/VitaTravel/

## 📌 About The Project

**VitaTravel** is a frontend clone of the **Vita Travel** website, originally discovered on **Awwwards**.

The project was created to practice and demonstrate modern frontend development techniques, including responsive UI design, smooth scrolling, animations, and interactive components.

### ✨ Features

* ⚛️ Built with React.js
* 🎨 Styled with Tailwind CSS
* 🎬 Smooth animations using GSAP
* 🖱️ Smooth scrolling using Lenis
* 📱 Responsive design for different screen sizes
* 🌍 Modern travel-focused UI
* ✨ Interactive animations and transitions
* 🚀 Deployed using GitHub Pages

## 🛠️ Technologies Used

* **React.js** – Frontend library
* **Tailwind CSS** – Styling and responsive design
* **GSAP** – Animations and scroll-based effects
* **Lenis** – Smooth scrolling
* **JavaScript** – Functionality and interactions
* **Vite** – Development and build tool
* **Git & GitHub** – Version control and deployment

## 🚀 Getting Started

Follow these steps to run the project on your local machine.

### 1. Install Node.js

First, make sure **Node.js** is installed on your computer.

You can download it from:

https://nodejs.org/

Check whether Node.js is installed:

```bash
node -v
```

Check npm:

```bash
npm -v
```

### 2. Clone the Repository

Open your terminal or command prompt and run:

```bash
git clone https://github.com/ayushtripathi20122004/VitaTravel.git
```

### 3. Go Inside the Project Folder

```bash
cd VitaTravel
```

### 4. Install Dependencies

Install all required packages:

```bash
npm install
```

### 5. Run the Development Server

Start the project using:

```bash
npm run dev
```

After that, Vite will provide a local URL, usually:

```text
http://localhost:5173/
```

Open that URL in your browser to view the website.
